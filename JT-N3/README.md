# RV3

Implementirajte algoritem za detekcijo jezika, ki temelji na osnovi znakovnih n-gramov. 

Podrobnejši opis delovanja algoritma najdete v prosojnicah in v naslednjem članku:

N-Gram-Based Text Categorization

Točkovanje

- Izgradnja profilov za naslednje jezike: angleščino, slovenščino, nemščino, španščino in hrvaščino. [2 točki]

- Program, ki podan dokument klasificira v enega izmed izdelanih profilov. [3 točke]

- Ločeno učenje in klasifikacija. [2 točki]

- Oddaja poročila, ki vsebuje opis programa, primere in rezultate testiranja. [3 točke]



English:

Implement a  n-gram based text categorization algorithm from the following article:

N-Gram-Based Text Categorization
